# portfolio-optimiser — highlights art

Card art for the portfolio-optimiser highlights modal, in carousel order.

Naming: `NN-light.png` and `NN-dark.png`, numbered from 01.

    01-light.png   01-dark.png
    02-light.png   02-dark.png
    ...

Specs, matching the Order form highlights:

- 1820 x 1200
- transparent PNG — the card draws no panel behind the art
- one pair per card; add as many as the project needs

The captions are config, not filenames: they live beside these paths in
src/config/projectGroups.ts and are matched by order.
